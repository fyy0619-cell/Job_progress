# qian_niu —— 个人职业发展路径规划

> 作者:fyy0619-cell · 起草时间:2026-05-23 · 目标:2027 秋招 + 2030 长远

本仓库是为「**电子/通信/自动化 硕士在读 → 2027 秋招高薪岗**」量身定制的一份**长期可迭代**的职业规划稿。
所有文档以"主线 = 端侧 AI / 模型部署 / 边缘智能,简历 = 具身智能"为基石,结合 2026 年当下的行业趋势、风险与机会成本展开。

---

## 1. 我是谁(基线)

- **学历:** 电子 / 通信 / 自动化方向 **硕士在读**(非计算机科班)
- **目标:** 2027 秋招(2026.08–2026.12 投递季)拿到高薪 offer,**2030 年前完成第一次跳槽**
- **主线决策(已拍板):** 端侧 AI / 模型部署 / 嵌入式 AI
- **简历亮点方向:** 具身智能(机器人感知 + 端侧推理)
- **在做的项目:** WS63 星闪 + Edge Impulse 跌倒检测(MCU + TinyML)
- **正在学:** STM32MP157(异构 A7+M4 + 嵌入式 Linux)

---

## 2. TL;DR 三条结论

1. **路径稳了别动:** 端侧 AI / 模型部署 是 EE 硕士跨向 AI 工程岗 **性价比最高的一条路**(避开顶会论文墙,工程含量足以撑起简历),2026–2028 仍是窗口期。
2. **MP157 选择性学,别 all-in:** 学 MP157 拿到的"嵌入式 Linux + 异构多核"是**通用底层硬通货**,但它**不是端侧 AI 主流硬件**(无 NPU,跑 NN 体验差)。建议**最多投入 3–4 周**作为 Linux 底子,然后立刻切到 **RK3588 / Jetson Orin Nano** 这类带 NPU 的真·端侧 AI 平台。详见 [02-MP157价值评估与决策.md](02-MP157价值评估与决策.md)。
3. **2026 暑期是分水岭:** 必须有一段端侧 AI / 推理部署相关的**实习或硬核个人项目**(具身智能感知 demo / 边缘 LLM 部署 / Jetson 上跑 YOLO+TensorRT 完整流水线),否则秋招简历会输给 CS 科班+论文 的同分位竞争者。
