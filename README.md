## 2. TL;DR 四条结论(2026-05-23 修正版)

1. ⚠ **方向有重大修正:** 原本推"纯端侧 AI 主线",经认真复盘后**新增推荐"AI BSP / NPU 系统软件复合路"作为最优解**(端侧 AI 主线 + Linux 内核底子双修)。这条路对 EE 硕士契合度 90%、应届起薪 45–60w、长远稳定性碾压纯端侧 AI。详见 **[07-端侧AI vs Linux驱动 长远对比.md](07-端侧AI%20vs%20Linux驱动%20长远对比.md) ★** —— **当下最优先阅读**。
2. **纯端侧 AI 仍是次优:** 若不喜欢 Linux 底层 debug,纯端侧 AI(方案 A)仍可走,2026–2028 风口期 + 起薪 50–70w,但 10 年后稳定性不如复合路。
3. **MP157 价值因路径而异:** 若选纯端侧 AI(方案 A),MP157 限 3–4 周;若选 AI BSP 复合路(方案 C,推荐),MP157 投入扩到 **6–8 周**,认真学 BSP + 驱动 + Yocto + RPMsg。**没 RK3588 不焦虑** —— ¥200 的 LuckFox Pico Plus(RV1106)就能撑起简历,且**研究它的 NPU 驱动源码是 AI BSP 路的简历金矿**。
4. **2026 暑期是分水岭:** 无论走哪条路,**必须有一段实习或硬核个人项目**(端侧 AI 部署 / NPU 驱动调试 / 异构多核 debug),否则秋招会输给 CS 科班+论文的同分位竞争者。
